# Blupn Web Sitesi Projesi

Bu paket web sitenizin hazır dosyalarını içerir.

## GitHub'a Nasıl Yüklenir?
1. GitHub hesabınıza giriş yapın.
2. Yeni bir repository oluşturun ve adını `blupn.github.io` yapın.
3. Bu zip dosyasını bilgisayarınızda bir klasöre çıkartın.
4. Çıkan `index.html` ve `style.css` dosyalarını doğrudan GitHub'daki repository'nizin içine sürükleyip bırakarak yükleyin.
5. Değişiklikleri kaydedin (Commit changes).
6. Birkaç dakika sonra siteniz `https://blupn.github.io` adresinde yayında olacaktır.
